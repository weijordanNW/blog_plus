## 遍历

```javascript
// 普通 for 循环（遍历性能最好）
for (let i = 0; i < list.length; ++i) { }

// for...in
for (const key in list) { }

// for...of
for (const item of list) { }

// forEach（仅遍历）
list.forEach(item => { });

// map（返回构造后的新数组）
list.map(item => { });
```

## 逻辑判断

```javascript
// every：全部返回 true 则函数返回 true
list.every(item => { });

// some：有一项返回 true，则函数返回 true（内部“或”关系）
list.some(item => { });
```

## 过滤

```javascript
// filter：返回过滤后的新数组
list.filter(item => { });
```

## 查找

```javascript
// indexOf：返回第一个找到的位置，否则为 -1
list.indexOf();

// lastIndexOf：返回最后一个找到的位置，否则为 -1
list.lastIndexOf();

// includes：接受一个参数，如果数组有目标值则返回 true
list.includes();

// find：如果找到目标值则返回目标值，否则返回 undefined
list.find();

// findIndex：如果找到目标值则返回下标，否则返回 -1
list.findIndex();
```
