## 示例代码结构

```javascript
// 清空前
let list = [1, 2, 3, 4, 5];
// 逻辑实现 ???
// 清空后
console.log(list); // []
```

## 方法一：重新赋值为空数组

```javascript
list = [];
```

- **复杂度**：O(1)

- **特点**：只是重新绑定一个新数组引用，不涉及旧数组的逐一删除。

- **缺点**：如果有其他变量引用了旧数组，该旧数组不会被清空。
	
```javascript
let arr = [1, 2, 3];
let ref = arr;
arr = [];
console.log(ref); // [1, 2, 3]  ← ref 仍然指向旧数组内容
```

## 方法二：使用 `splice`

```javascript
arr.splice(0, arr.length);
```

- **复杂度**：O(n)（n 为数组长度）

- **原因**：`splice` 需要返回被删除的元素，内部会对每个元素进行操作。
	
## 方法三：循环 `pop`

```javascript
while (arr.length) {
    arr.pop();
}
```

- **复杂度**：O(n)

- **原因**：`pop()` 每次删除数组最后一个元素，单次复杂度 O(1)，但需要执行 n 次。
	
## 方法四：循环 `shift`

```javascript
while (arr.length) {
    arr.shift();
}
```

- **复杂度**：O(n²)

- **原因**：`shift()` 删除数组第一个元素时，需要将剩余的所有元素整体前移，每次操作平均 O(n)，循环 n 次即 O(n²)。**不推荐用于大数组**。
	
## 方法五：直接设置 `length` 为 0

```javascript
arr.length = 0;
```

- **优点**：原地清空，所有引用同步清空。是最彻底、最高效的清空方法。

- **复杂度**：O(1)（仅修改长度属性，不遍历元素）
