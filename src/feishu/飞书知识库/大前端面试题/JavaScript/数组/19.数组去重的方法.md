# 文档：数组去重的方法

## 1. 使用 Set


`Set` 只允许存储唯一的值，可以将数组转换为 `Set`，再通过扩展运算符转换回数组以实现去重。


```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = [...new Set(arr)];
```

## 2. 使用 filter 和 indexOf


利用 `filter` 方法遍历数组，只保留第一次出现的元素。


```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = arr.filter((value, index, self) => self.indexOf(value) === index);
```

## 3. 使用 reduce 和 includes


使用 `reduce` 方法逐个遍历数组元素，构建一个新数组，只添加尚未存在的元素。


```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = arr.reduce((acc, current) => {
    if (!acc.includes(current)) {
        acc.push(current);
    }
    return acc;
}, []);
```

## 4. 使用 forEach 和 indexOf


遍历数组，对于每个元素，若其不在新数组中（`indexOf === -1`），则添加到新数组。


```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = [];
arr.forEach((value) => {
    if (uniqueArr.indexOf(value) === -1) {
        uniqueArr.push(value);
    }
});
```

## 5. 使用 forEach 和 includes


与 `indexOf` 类似，但使用 `includes` 判断元素是否已存在于新数组中。


```javascript
const arr = [1, 2, 2, 3, 4, 4, 5];
const uniqueArr = [];
arr.forEach((value) => {
    if (!uniqueArr.includes(value)) {
        uniqueArr.push(value);
    }
});
```
