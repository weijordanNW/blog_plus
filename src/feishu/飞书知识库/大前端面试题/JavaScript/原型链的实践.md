# 原型链的实践 - 以下代码输出 2 的原因

```javascript
const Foo = function () {
    this.a = function() {
        console.log('2')
    }
}

Foo.prototype.a = function() {
    console.log('3')
}

Foo.a = function () {
    console.log('4')
}

let obj = new Foo();
obj.a(); // 打印 2
```


输出结果为 `2`，当 JavaScript 尝试访问一个方法的属性时，首先会在实例本身去寻找，找不到就会往 `prototype` 上找。在该案例中，`Foo` 实例本身就已经拥有了 `a` 方法，所以就会直接执行，输出 `2`。


- 当 `Foo` 中没有 `a` 方法时，就会寻找到 `prototype` 上的 `a` 方法，输出 `3`。

- 而 `Foo.a` 则是 `Foo` 的静态方法，通过 `Foo.a()` 直接执行，输出 `4`。
