## 问题


以下代码输出什么结果？


```javascript
console.log(s);
var s = 2;
function s() {}
console.log(s);
```

## 答案

```javascript
[Function: s]
2
```

## 原理解析

- `var` 声明的变量会存在**变量提升**（但只提升声明，不提升赋值）。

- **函数提升的优先级高于变量提升**。即函数声明会提升到最前面，变量声明虽然后面也会提升，但会被函数声明覆盖。
	
## 代码演变过程

### 第一步：函数提升优先


函数 `function s() {}` 被提升到当前作用域的最顶部。


```javascript
function s() {}
console.log(s);
var s = 2;
console.log(s);
```

### 第二步：变量声明提升（但不会覆盖函数声明）


`var s` 的声明也会提升，但由于同名标识符已存在（函数 `s`），变量声明不会覆盖函数声明。



等价于：


```javascript
function s() {}
console.log(s);   // [Function: s]
s = 2;            // 变量赋值
console.log(s);   // 2
```

## 最终输出

```plaintext
[Function: s]
2
```
