### 推荐
```javascript
Reflect.ownKeys(obj).length === 0;
```

---
## 1. 常用方法（存在局限性）


以下方法在大多数情况下可以判断对象是否为空，但**无法处理以 Symbol 作为属性名**的对象。


```javascript
// 方法一：判断自身可枚举属性个数
Object.keys(obj).length === 0;

// 方法二：序列化比较
JSON.stringify(obj) === '{}';

// 方法三：for...in 遍历判断
let isEmpty = true;
for (let key in obj) {
  if (obj.hasOwnProperty(key)) {
    isEmpty = false;
    break;
  }
}
```

## 2. 局限性说明


上述方法**不严谨**，例如对于以下对象：


```javascript
const obj = { [Symbol('a')]: 1 };
```

- `Object.keys(obj)` 返回 `[]`（忽略 Symbol 属性）

- `JSON.stringify(obj)` 返回 `'{}'`（忽略 Symbol 属性）

- `for...in` 无法遍历 Symbol 属性
	
因此会被误判为空对象。


## 3. 更严谨的判断方法


使用 `Reflect.ownKeys(obj)`，它可以返回对象自身的**所有属性键**，包括**字符串键**和**Symbol 键**。


```javascript
Reflect.ownKeys(obj).length === 0;
```


该方法能够正确处理包含 Symbol 属性的对象，是更推荐的判断方式。
