## 1. 对象字面量（Object Literal）


使用大括号 `{}` 创建对象，可以在大括号内定义对象的属性和方法。


```javascript
var person = {
    name: "Alice",
    age: 30,
    sayHello: function() {
        console.log("Hello!");
    }
};
```

## 2. 构造函数（Constructor Function）


使用构造函数创建对象，通过 `new` 关键字调用以创建对象。


```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
}
var person1 = new Person("Alice", 30);
```

## 3. `Object.create()` 方法


使用 `Object.create()` 方法创建对象，可以指定对象的原型。


```javascript
var person = Object.create(null); // 创建一个空对象
person.name = "Alice";
person.age = 30;
```

## 4. 工厂函数（Factory Function）


工厂函数是一个返回新对象的函数。


```javascript
function createPerson(name, age) {
    return {
        name: name,
        age: age,
    };
}
var person1 = createPerson("Alice", 30);
```

## 5. 类（ES6 中引入的类）


使用类定义对象，类是一种对象构造器的语法糖。


```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
}
var person1 = new Person("Alice", 30);
```
