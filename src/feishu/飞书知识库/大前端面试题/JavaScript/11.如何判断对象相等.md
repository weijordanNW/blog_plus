## 常用方法

```javascript
JSON.stringify(obj1) === JSON.stringify(obj2)
```


该方法将两个对象序列化为 JSON 字符串后进行比较，适用于**浅层、属性顺序一致**的简单对象。


## 注意事项

- 对象的属性顺序不同可能导致 `false`（即使内容相同）

- 无法处理 `undefined`、函数、`Symbol`、循环引用等特殊值

- `NaN` 和 `Infinity` 会序列化为 `null`

- 不适合包含日期、正则表达式等类型的对象
	
> 更严谨的方式通常需要递归比较（深比较）或使用 Lodash 的 `_.isEqual` 等方法。
