# 字符串转数字的方法

## 使用 `parseInt`（转换为整数）

```javascript
const str = "123";
const num = parseInt(str);
console.log(num); // 123
```


> 注意：`parseInt` 会解析整数部分，不会保留小数。


## 使用 `parseFloat`（转换为浮点数）

```javascript
const str = "3.14";
const num = parseFloat(str);
console.log(num); // 3.14
```

## 使用 `Number` 构造函数

```javascript
const str = "42";
const num = Number(str);
console.log(num); // 42
```


> `Number()` 可以同时转换整数和浮点数，但如果字符串包含非数字字符（除空格、正负号、小数点外），会返回 `NaN`。
