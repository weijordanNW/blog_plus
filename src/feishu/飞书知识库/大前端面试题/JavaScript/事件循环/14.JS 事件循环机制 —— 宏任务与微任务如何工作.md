## 一、基本原理


事件循环的宏观流程如下：


1. 同步任务直接执行。

1. 遇到微任务，放入微任务队列（如 `Promise.then`、`process.nextTick` 等）。

1. 遇到宏任务，放入宏任务队列（如 `setTimeout`、`setInterval` 等）。

1. 执行完所有同步任务。

1. 执行微任务队列中的所有任务（清空微任务队列）。

1. 执行一个宏任务（从宏任务队列取出一个执行）。

1. 重复上述过程（再次检查微任务 → 执行下一个宏任务……）。
	
```plaintext
开始执行 → 同步代码 → 执行完毕 → 清空微任务队列 → 执行一个宏任务 → 循环
```

## 二、案例：问打印顺序


以下代码的输出顺序是什么？


```javascript
console.log(1);
Promise.resolve().then(() => {
    console.log(2);
    setTimeout(() => {
        console.log(3);
    }, 0);
});
setTimeout(() => {
    console.log(4);
    new Promise((resolve) => {
        console.log(5);
        resolve();
    }).then(() => {
        console.log(6);
    });
}, 0);
console.log(7);
```


**输出结果**：`1, 7, 2, 4, 5, 6, 3`


## 三、过程逐步分析

### 第一步：执行同步任务

- 输出 `1`

- 输出 `7`
	
此时状态：
- 宏任务队列中已放入：第二个 `setTimeout` 的回调（内容：输出4、执行Promise并输出5、添加微任务输出6）

- 微任务队列中已放入：`Promise.resolve().then` 的回调（内容：输出2、再添加一个 setTimeout 输出3）
	
```javascript
// 宏任务队列
const macroTaskQueue = [
    { /* 第二个 setTimeout 的回调：console.log(4); ... */ }
];

// 微任务队列
const microTaskQueue = [
    { /* Promise.then 回调：console.log(2); 然后 setTimeout(...,0) 添加宏任务 */ }
];
```


> 此时输出：`1, 7`


### 第二步：同步代码执行完毕，开始清空微任务队列


执行微任务队列中的第一个（也是唯一一个）任务：
- 输出 `2`

- 遇到 `setTimeout(() => console.log(3), 0)`，将其回调放入宏任务队列末尾。
	
宏任务队列现在有两个任务：
1. 第二个 `setTimeout` 的回调（输出4、5、6）

1. 新添加的输出3的回调
	
微任务队列清空。



> 此时输出：`1, 7, 2`


### 第三步：执行一个宏任务（FIFO）


取出宏任务队列的第一个任务（输出4、5、6的回调）：
- 输出 `4`

- 执行 `new Promise(...)`，其同步代码输出 `5`

- `resolve()` 触发 `.then`，将输出6的回调放入微任务队列。
	
此时微任务队列有一个任务：输出 `6`。



> 此时输出：`1, 7, 2, 4, 5`


### 第四步：再次清空微任务队列


执行微任务队列中的任务：
- 输出 `6`
	
微任务队列清空。



> 此时输出：`1, 7, 2, 4, 5, 6`


### 第五步：再执行下一个宏任务


宏任务队列中现在只有一个任务（输出3的回调）：
- 输出 `3`
	
宏任务队列清空。



> 最终输出：`1, 7, 2, 4, 5, 6, 3`


## 四、流程总结


| 阶段      | 输出   | 宏任务队列状态            | 微任务队列状态     |
| ------- | ---- | ------------------ | ----------- |
| 同步任务    | 1, 7 | [宏1(4,5,6)]        | [微1(2,加宏2)] |
| 清空微任务   | 2    | [宏1(4,5,6), 宏2(3)] | 空           |
| 执行一个宏任务 | 4,5  | [宏2(3)]            | [微3(6)]     |
| 清空微任务   | 6    | [宏2(3)]            | 空           |
| 执行一个宏任务 | 3    | 空                  | 空           |



**最终顺序**：`1 → 7 → 2 → 4 → 5 → 6 → 3`
