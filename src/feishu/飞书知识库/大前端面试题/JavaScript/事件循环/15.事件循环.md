## 代码

```javascript
setTimeout(() => {  
    console.log('timeout')  
});  

function test() {  
    console.log('test');  
    return Promise.resolve().then(() => {  
        test()  
    });  
}  

test();
```

## 考察重点


事件循环中，**宏任务与微任务的执行优先级**。


## 答案


**持续输出 **`**test**`**，且不会输出 **`**timeout**`。


## 原理解析

- `setTimeout` 的回调属于**宏任务**，会被放入宏任务队列。

- `Promise.resolve().then()` 的回调属于**微任务**，会被放入微任务队列。

- 事件循环的规则是：**每次执行完同步代码后，会先清空整个微任务队列，然后再从宏任务队列中取出一个宏任务执行**。

- 本例中，`test()` 第一次执行时输出 `test`，并立即向微任务队列中添加一个微任务（即 `then` 回调），该微任务又会调用 `test()`，从而不断往微任务队列中添加新的微任务。

- 由于微任务队列**永远不为空**，事件循环会持续处理微任务，永远无法进入宏任务队列去执行 `setTimeout` 的回调。

- 因此，`'timeout'` 永远不会被输出。
