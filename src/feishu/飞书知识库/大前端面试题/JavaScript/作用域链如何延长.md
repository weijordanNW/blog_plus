# 文档：作用域链如何延长


作用域链可以通过**闭包**来延长。闭包使得函数内部可以访问外部函数的变量，即使外部函数已经执行完毕。这些变量会继续保留在内存中，从而延长了作用域链。


## 示例：闭包延长作用域链

```javascript
function makeCounter() {
    var count = 0;
    return function() {
        count++;
        return count;
    };
}

var counter1 = makeCounter();
var counter2 = makeCounter();

console.log(counter1()); // 1
console.log(counter1()); // 2
console.log(counter2()); // 1，每个 counter 具有自己的作用域链，且都延长了 count 的作用域
```

## 说明

- 每次调用 `makeCounter()` 都会创建一个新的作用域对象，其中包含变量 `count`，并返回一个内部函数。

- 内部函数引用了外部函数的 `count` 变量，形成了闭包，从而延长了 `count` 的作用域。

- 返回的函数（如 `counter1` 和 `counter2`）各自持有对独立 `count` 变量的引用，互不影响。
