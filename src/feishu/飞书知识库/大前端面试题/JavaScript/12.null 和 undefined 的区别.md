## undefined


`undefined` 表示一个变量已被声明但尚未被赋值，或某个属性、元素不存在。



常见出现 `undefined` 的场景：


- 声明了变量但未初始化时，其值为 `undefined`。

- 访问对象中不存在的属性或数组中不存在的索引时，返回 `undefined`。

- 函数没有显式返回值时，默认返回 `undefined`。

- 函数参数未传递或被省略时，对应参数的值为 `undefined`。
	
```javascript
let x;
console.log(x); // undefined

const obj = {};
console.log(obj.property); // undefined

function exampleFunc() {
    // 没有 return
}
console.log(exampleFunc()); // undefined

function add(a, b) {
    return a + b;
}
console.log(add(2)); // NaN（b 为 undefined，计算得 NaN）
```

## null


`null` 是一个特殊的关键字，表示一个**空对象指针**。



特点：


- 通常用于**显式**地指示一个变量或属性的值为空。

- `null` 是一个赋值操作，表示“没有值”或“空”。

- `null` 不会自动被分配给变量，需要开发人员主动赋值。

- `null` 是原型链的顶层：所有对象都继承自 `Object` 原型对象，而 `Object` 原型的原型是 `null`。
	
```javascript
const a = null;
console.log(a); // null

const obj = { a: 1 };
const proto = obj.__proto__;
console.log(proto.__proto__); // null
```

## 核心区别总结


| 特性        | undefined                          | null                            |
| --------- | ---------------------------------- | ------------------------------- |
| 语义        | 未定义（变量声明未赋值）                       | 空值（主动赋值为空）                      |
| 类型        | `typeof undefined` → `"undefined"` | `typeof null` → `"object"`      |
| 自动产生      | 是（默认值）                             | 否（需显式赋值）                        |
| 原型链顶层     | 否                                  | 是（`Object.prototype.__proto__`） |
| 与 `==` 比较 | `null == undefined` → `true`       | `null === undefined` → `false`  |
