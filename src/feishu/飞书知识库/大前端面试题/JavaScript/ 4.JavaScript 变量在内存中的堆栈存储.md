引用类型存放于堆，基本类型存放于栈。
## 示例代码
```javascript

function fn(obj) {
  obj = { m: 50 };
  console.log(obj.m); // 输出什么？ 50
}

const o = { m: 30 };
fn(o);
console.log(o.m); // 输出什么？ 30
```
## 解析

- 执行 `const o = { m: 30 }` 时，在堆内存中开辟空间存储 `{ m: 30 }`，变量 `o`（存放于栈）记录该堆内存地址。

- 调用 `fn(o)` 时，将 `o` 存储的地址复制给参数 `obj`，此时 `obj` 也指向同一对象 `{ m: 30 }`。

- 在函数内部执行 `obj = { m: 50 }`，将 `obj` 指向一个新对象（堆中新开辟的空间），此时 `obj` 与外部 `o` 指向不同对象。

- 因此 `console.log(obj.m)` 输出 **50**，而外部的 `console.log(o.m)` 仍输出原来的 **30**。

![image](https://raw.githubusercontent.com/weijordanNW/blog_plus/main/feishu/OUlTb9nYhoIgGBxMjV6cOpJMnFI.png)
- 接着执行 `fn(o)`，会把 `o` 记录的地址值作为实参传递到方法 `fn` 中，同时记录在 `obj` 副本变量中（注意：JS 的传参都是值传递）。

- 再下来执行 `obj = { m: 50 }`，相当于重新开辟了一个堆内存空间存储 `{ m: 50 }`，同时把地址记录到 `obj` 中。
![image](https://raw.githubusercontent.com/weijordanNW/blog_plus/main/feishu/PrsQbh1IBobKkKxCMYUc28Oknac.png)


- 然后执行 `console.log(obj.m)`，会根据 `obj` 记录的地址2，找到 `{ m: 50 }`，所以输出 ****50****。

- 最后同理，执行 `console.log(o.m)`，会根据 `o` 记录的地址1，找到 `{ m: 30 }`，所以输出 ****30****。
