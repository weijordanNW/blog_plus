## 类数组的定义


类数组（或伪数组）是一种类似数组的对象，它们具有类似数组的结构，即具有数字索引和 `length` 属性，但**不具有**数组对象上的方法和功能（如 `push`、`pop`、`forEach` 等）。


## 常见的类数组

- 函数内部的 `arguments` 对象

- DOM 元素列表（例如通过 `document.querySelectorAll` 获取的元素集合）

- 一些内置方法返回的集合（如 `getElementsByTagName` 返回的集合）
	
## 类数组转化为真实数组的方法

### 1. `Array.from()` 方法

```javascript
const nodeList = document.querySelectorAll('.my-elements'); // 获取DOM元素集合（类数组）
const arrayFromNodeList = Array.from(nodeList); // 转换为真实数组
```

### 2. `Array.prototype.slice.call()` 方法

```javascript
const nodeList = document.querySelectorAll('.my-elements'); // 获取DOM元素集合（类数组）
const arrayFromNodeList = Array.prototype.slice.call(nodeList); // 转换为真实数组
```

### 3. 扩展运算符（Spread 运算符）

```javascript
var nodeList = document.querySelectorAll('.my-elements'); // 获取DOM元素集合（类数组）
var arrayFromNodeList = [...nodeList]; // 转换为真实数组
```
