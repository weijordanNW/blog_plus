- 常用方法：
	- `Object.keys(obj).length === 0`
		- `JSON.stringify(obj) === '{}'`
		- `for in` 判断
		
- 以上方法都不太严谨，因为处理不了 `const obj = { [Symbol('a')]: 1 }` 这种情况。
	
- 更严谨的方法：`**Reflect.ownKeys(obj).length === 0;**`

## 总结

最终建议：如果你需要处理可能包含不可枚举或 Symbol 属性的对象，使用 

`Reflect.ownKeys(obj).length === 0`。

如果确定对象只含有常规的可枚举字符串属性，

`Object.keys(obj).length === 0` 

更简单高效。
