## 1. 使用递归 setTimeout 实现倒计时

```javascript
const countDown = (count) => {
  setTimeout(() => {
    count--;
    if (count > 0) {
      countDown(count);
    }
  }, 1000);
  countDown(10);
}
```


> **说明**：每次执行完后，再设置下一个定时器。这种方式可以保证两次任务之间的间隔**固定为 1 秒**（忽略代码执行耗时）。


## 2. 使用 setInterval 实现倒计时
原示例：


```javascript
let count = 10;
let timer = setInterval(() => {
  count--;
  if (count <= 0) {
    clearInterval(timer);
    timer = null;
  }
}, 1000);
```

## 3. setTimeout 与 setInterval 的区别


| 方式                | 行为特点                                                                   |
| ----------------- | ---------------------------------------------------------------------- |
| **递归 setTimeout** | 每次任务执行完毕后再设置下一次定时器，**任务之间的间隔保证 ≥ 指定时间**（通常等于指定时间）。                     |
| **setInterval**   | 无视上一个任务是否执行完毕，**每隔固定时间**向任务队列添加任务。若任务执行时间 > 间隔时间，会导致任务堆积，实际执行间隔小于设定间隔。 |



> **PS**：`setInterval` 中当任务执行时间大于任务间隔时间时，会导致“消费赶不上生产”，任务不断堆积，可能造成性能问题或逻辑错误。
