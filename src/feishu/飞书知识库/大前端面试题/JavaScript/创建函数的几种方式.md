## 1. 函数声明（Function Declaration）


使用 `function` 关键字定义函数，可以在任何位置声明并使用。函数声明会提升（hoisting），所以可以在声明之前调用函数。


```javascript
function sayHello() {
    console.log("Hello, World!");
}
sayHello(); // 调用函数
```

## 2. 函数表达式（Function Expression）


将函数赋值给变量或属性，函数表达式的名称是可选的。与函数声明不同，函数表达式不会提升。


```javascript
var sayHi = function() {
    console.log("Hi there!");
};
sayHi(); // 调用函数

// 匿名函数表达式
var greet = function(name) {
    console.log("Hello, " + name);
};
greet("Alice"); // 调用函数
```

## 3. 箭头函数（Arrow Function）


箭头函数是 ES6 引入的一种函数声明方式，具有更短的语法和词法作用域。箭头函数没有自己的 `this`，它继承自外围作用域。


```javascript
const add = (a, b) => a + b;
console.log(add(2, 3)); // 输出 5
```

## 4. 匿名函数（Anonymous Function）


函数没有名字，通常用于回调函数或临时函数。


```javascript
setTimeout(function() {
    console.log("This is an anonymous function.");
}, 1000);
```
