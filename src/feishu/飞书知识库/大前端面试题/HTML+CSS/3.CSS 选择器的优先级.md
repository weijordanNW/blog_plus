```markdown
┌─────────────────────────────────────────────────────────────────────────────┐
│                        CSS 选择器优先级 & 权重计算方式                        │
├───────────────────┬─────────────────────────────────────────────────────────┤
│ 1. !important 规则 │ 含 !important 的样式声明，优先级最高（覆盖无 !important 规则） │
├───────────────────┼─────────────────────────────────────────────────────────┤
│                   │ 按「特定性值」排序，值越大优先级越高。                     │
│ 2. 特定性（特异性） │ 特定性值分配：                                         │
│                   │  - 内联样式 → 1000/个                                   │
│                   │  - ID 选择器 → 100/个                                   │
│                   │  - 类/属性/伪类选择器 → 10/个                           │
│                   │  - 元素/伪元素选择器 → 1/个                             │
│                   │ 案例：                                                 │
│                   │   #header → 100（1 个 ID）；                            │
│                   │   .menu-item → 10（1 个类）；                           │
│                   │   ul li → 2（2 个元素）                                 │
├───────────────────┼─────────────────────────────────────────────────────────┤
│ 3. 覆盖规则       │ 特定性相同时，后定义的规则覆盖先定义的规则（后定义优先级更高） │
└───────────────────┴─────────────────────────────────────────────────────────┘
```
