HTML语义化标签是指用具有明确含义的标签来标记网页内容，使结构更清晰，便于浏览器、搜索引擎和开发者理解。它们不仅描述“外观”，更描述“内容角色”。


### 常见语义化标签及用途


| 标签                          | 含义                     |
| --------------------------- | ---------------------- |
| `<header>`                  | 页眉，通常包含导航、logo、标题等     |
| `<nav>`                     | 导航链接区域                 |
| `<main>`                    | 页面主要内容（每个页面唯一）         |
| `<article>`                 | 独立、可复用的内容（如博客文章、新闻）    |
| `<section>`                 | 文档中的一节，通常带标题           |
| `<aside>`                   | 侧边栏，与主内容间接相关（如广告、相关链接） |
| `<footer>`                  | 页脚，包含版权、联系方式等          |
| `<figure>` 和 `<figcaption>` | 图表/图片及其标题              |
| `<mark>`                    | 高亮文本                   |
| `<time>`                    | 日期或时间                  |
| `<details>` 和 `<summary>`   | 可折叠的详情框                |


### 为什么重要？

1. **SEO**：搜索引擎更准确抓取关键内容（如`<article>`里的正文）。

1. **可访问性**：屏幕阅读器可快速跳转到导航、主内容等区域，帮助视障用户。

1. **代码可维护性**：结构清晰，团队协作容易。

1. **未来兼容**：标准化的标签能更好适应浏览器演进。
	
### 对比非语义化标签

- 非语义化：`<div>`、`<span>` —— 无任何含义，仅用于布局或样式。

- 语义化：用`<header>`代替`<div class="header">`，用`<nav>`代替`<div class="nav">`。
	
### 示例代码

```html
<header>
  <h1>我的博客</h1>
  <nav>
    <a href="/">首页</a>
    <a href="/articles">文章</a>
  </nav>
</header>

<main>
  <article>
    <h2>HTML语义化介绍</h2>
    <p>发布于<time datetime="2025-03-20">2025年3月20日</time></p>
    <section>
      <h3>为什么要语义化</h3>
      <p>...</p>
    </section>
  </article>

  <aside>
    <h3>相关推荐</h3>
    <ul>...</ul>
  </aside>
</main>

<footer>
  <p>© 2025 我的博客</p>
</footer>
```


使用语义化标签是构建高质量网页的基础实践。
