CSS3 中的**伪类**（pseudo-classes）和**伪元素**（pseudo-elements）都是用来选择文档中特定部分的选择器，但它们的用途和语法有明显区别。


## 一、伪类（Pseudo-classes）
- **语法**：单冒号 `:`

- **作用**：选择元素的**特定状态**（如悬停、被访问、焦点等）或**特定位置的子元素**（如第一个子元素、偶数行等）。

- **不创建新元素**，只是基于现有元素的动态或静态特征进行筛选。
	
### 常见伪类示例

| 伪类                          | 说明                      |
| --------------------------- | ----------------------- |
| `:hover`                    | 鼠标悬停时                   |
| `:active`                   | 元素被激活（如点击瞬间）            |
| `:focus`                    | 获得焦点（如输入框）              |
| `:visited`                  | 已访问过的链接                 |
| `:first-child`              | 父元素下的第一个子元素             |
| `:last-child`               | 父元素下的最后一个子元素            |
| `:nth-child(n)`             | 父元素下第 n 个子元素            |
| `:not(selector)`            | 排除匹配指定选择器的元素            |
| `:is(selector1, selector2)` | 匹配括号内任意选择器（CSS3 引入，更简洁） |
| `:where(selector)`          | 同 `:is`，但优先级为 0         |
| `:has(selector)`            | 包含指定子元素的父元素（CSS3 渐进支持）  |


## 二、伪元素（Pseudo-elements）
- **语法**：双冒号 `::`（CSS3 规范，但为兼容旧浏览器，单冒号也常见）

- **作用**：创建**不在 DOM 树中的虚拟元素**，用于样式化文档的特定部分（如首字母、首行、插入内容）。

- **实际上是生成了一个新盒子**，可以通过 `content` 属性插入内容。
	
### 常见伪元素示例

| 伪元素              | 说明                           |
| ---------------- | ---------------------------- |
| `::before`       | 在元素内容之前插入虚拟内容（需配合 `content`） |
| `::after`        | 在元素内容之后插入虚拟内容                |
| `::first-letter` | 选中元素文本的第一个字母                 |
| `::first-line`   | 选中元素文本的第一行                   |
| `::selection`    | 用户选中的文本部分（背景、颜色等）            |
| `::placeholder`  | 输入框的占位符文本样式                  |
| `::marker`       | 列表项（`<li>`）的标记符号样式           |


## 三、核心区别总结


| 特性            | 伪类                       | 伪元素                          |
| ------------- | ------------------------ | ---------------------------- |
| 语法            | `:`                      | `::`（推荐）                     |
| 本质            | 状态/位置过滤器                 | 创建虚拟元素                       |
| 是否生成新对象       | 否                        | 是                            |
| 能否用 `content` | 否                        | 是（仅 `::before`/`::after`）    |
| 常见例子          | `:hover`, `:nth-child()` | `::before`, `::first-letter` |


## 四、典型代码示例
```css
/* 伪类：悬停改变按钮颜色 */
button:hover {
  background-color: blue;
}

/* 伪元素：段落首字母下沉 */
p::first-letter {
  font-size: 2em;
  font-weight: bold;
}

/* 伪元素：在链接前添加图标 */
a::before {
  content: "🔗 ";
}
```

## 五、注意事项
1. **CSS3 明确要求**伪元素使用双冒号 `::`，伪类使用单冒号 `:`，但旧浏览器也支持单冒号写法。

1. 一个选择器中可以同时使用伪类和伪元素，如 `div:hover::before {}`。

1. 某些伪类（如 `:nth-child`）实际上是在 CSS3 中被重新定义和扩展的，但基础版本来自 CSS2。

1. 较新的 CSS3 伪类（如 `:is`、`:where`、`:has`）在现代浏览器中已普遍支持，但需要注意兼容性。
