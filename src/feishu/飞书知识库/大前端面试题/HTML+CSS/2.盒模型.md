CSS 盒子模型（Box Model）是网页布局的基础，它描述了每个元素如何占用空间。理解盒子模型对精准控制元素尺寸、间距及边框至关重要。


## 核心组成部分
一个元素的盒子由**四层**从内到外组成：
1. **内容（Content）**：文本、图片等实际内容所占区域。可通过 `width`/`height` 控制（默认仅影响内容区）。

1. **内边距（Padding）**：内容与边框之间的透明区域，用于增加内部空间。通过 `padding` 设置。

1. **边框（Border）**：包围内边距和内容的边界线。通过 `border` 设置（宽度、样式、颜色）。

1. **外边距（Margin）**：元素与相邻元素之间的透明间隔，用于控制外部距离。通过 `margin` 设置。
	
## 两种盒子模型（box-sizing）
- **content-box（默认）**：`width` = 仅内容宽度；实际占宽 = 内容宽 + 左右padding + 左右border。易导致布局溢出。

- **border-box**：`width` = 内容宽 + padding + border；总宽度固定，更符合直觉。推荐使用 `* { box-sizing: border-box; }` 全局重置。
	
## 计算公式（border-box时）
元素总宽度 = 设置的 `width` + 左右 `margin`

元素总高度 = 设置的 `height` + 上下 `margin`


## 边距折叠（Margin Collapse）
- 垂直相邻块级元素的上下 `margin` 会合并，取最大值（非相加）。

- 父子、空元素也会发生折叠。可通过设置 `padding`/`border`、`overflow: hidden` 或 `display: flex` 等阻止。
	
## 示例对比
```css
/* 默认 content-box */
.box1 {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  /* 实际占宽 = 200 + 40 + 10 = 250px */
}

/* border-box 版本 */
.box2 {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  /* 实际占宽 = 200px（内容区自动压缩到150px） */
}
```
